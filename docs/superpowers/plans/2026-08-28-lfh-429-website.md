# LFH-429 Dokumentationswebsite — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `packages/website` liefert eine deutsch geschriebene, eigens gestaltete Astro/Starlight-Site mit Quickstart, Symbol Explorer, Builder, Coverage, MapLibre Lab, generierten Symbolseiten und Statusseiten; CI baut sie als Artefakt.

**Architecture:** Statische Seiten importieren den Katalog direkt zur Buildzeit (Node). Browser-Islands (React) bekommen ihre Daten aus einem generierten, policy-geprüften Katalog-Snapshot und importieren nur node-freie Pakete (`core`, `schema`, `react`, `maplibre`). Ein Snapshot-Generator ist die einzige Grenze zwischen Katalog und Website.

**Tech Stack:** Astro 7.2, Starlight 0.41, @astrojs/react 6, React 19, maplibre-gl 6.6, Vitest 3.2 (Root-Config), happy-dom, pnpm 11, Node 22.

**Spec:** `docs/superpowers/specs/2026-08-28-lfh-429-website-design.md`

## Global Constraints

- Sprachregeln aus Spec §3 gelten für jeden Prosatext: deutsch, aktiv, konkret, Zahlen mit Quelle, AFKzV-Status wörtlich aus `README.md` (Zeilen 88–102), keine Lizenzaussagen über README/LFH-432-Vorlage hinaus.
- Islands importieren **nie** `@einsatzzeichen/catalog` über den Index (zieht `node:url`). Daten kommen aus `src/generated/catalog-snapshot.json`.
- Nichts aus `taktische-zeichen/`, `out/`, keine `referenceAsset`-Werte, keine absoluten Pfade in Snapshot, HTML oder Repo (`pnpm cli verify:repository`).
- Organisationsfarben nur in Zeichen, nie als Dekor. Statusmarken immer mit Textlabel.
- Kein Deploy, kein Secret, kein Pages-Job.
- Astro-/Starlight-APIs vor Verwendung gegen context7 (`/withastro/docs`, `/withastro/starlight`) prüfen — Astro 7 ist neuer als das Modellwissen.
- Commit-Messages deutsch im Projektstil (`feat(website): …`), Trailer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- Jede Task endet mit `pnpm test`, `pnpm typecheck` und (ab Task 0) `pnpm --filter @einsatzzeichen/website build` grün.
