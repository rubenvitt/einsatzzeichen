`@einsatzzeichen/cli` ist das Werkzeug am Rand: es liest die lokale Referenz, rechnet Kennzahlen
aus, prüft Gates und schreibt SVG-Dateien. Es ist das einzige Paket mit einer Fremdabhängigkeit
zum Rastern (`@resvg/resvg-js`) und das einzige, das auf das Dateisystem zugreift.

Die Zahlen dieser Website und die Zahlen von `pnpm cli coverage` stammen aus denselben Funktionen
im Katalog. Wer nachrechnen will, ruft das Kommando auf und vergleicht.

## Installation

<div class="ez-note">
<span class="ez-note__title">Nicht veröffentlicht</span>

Aufruf im Repository über das Root-Skript:

```bash
pnpm cli coverage
```

</div>

## Kommandos

| Kommando | Was es tut |
|---|---|
| `coverage` | die drei Coverage-Achsen, die Blocker und den Stand der fachlichen Reviews |
| `verify:repository` | Repository-Policy: keine Referenzassets im Git-Index, keine verletzte Paketgrenze |
| `audit:reference [--filter <präfix>] [--print]` | Kennzahlen aus dem lokalen Referenzbestand |
| `review-dossier [--out <md-pfad>]` | Dossier der fachlichen Reviews als Markdown |
| `export [--out <pfad>] [--size <px>] [--theme <reference\|accessible-light\|print-monochrome>]` | alle Zeichen als SVG-Dateien |
| `visual-proof --reference-root <pfad> [--out <png-pfad>]` | Sichtprüfungsblatt als PNG |

## Beispiel

```bash
# Coverage mit denselben Zahlen wie auf der Seite „Stand der Prüfung“ dieser Website
pnpm cli coverage

# Alle Zeichen als 256-px-SVG im Druckprofil
pnpm cli export --out ./out/svg --size 256 --theme print-monochrome
```

Das Repository-Gate läuft vor allem anderen und bricht mit Klartext ab, wenn eine Regel verletzt
ist:

```bash
pnpm cli verify:repository
# Repository-Gate bestanden.
```
