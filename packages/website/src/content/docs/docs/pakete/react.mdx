Diese Seite richtet sich an Entwicklerinnen und Entwickler. Wer ein Zeichen nur finden,
herunterladen, drucken oder auf eine Karte legen möchte, braucht sie nicht — dafür gibt es
die [Anleitungen](/docs/anleitungen/).

`@einsatzzeichen/react` trägt das SVG aus `core` in den React-Baum — und zwar bytegleich. Die
Komponente rendert nicht selbst: sie ruft `renderSvg`, zerlegt das Ergebnis in Wurzelattribute und
Inhalt und setzt beides ein. Damit ist ausgeschlossen, dass React ein anderes Bild erzeugt als der
Kanal daneben.

Kein JSX-Build im Paket, `react` ist Peer-Abhängigkeit (`>=18`). Das Paket importiert `core` und
`schema`, aber **nicht** das Prüfpaket `conformance` — die Zeichnung kommt über die Anwendung herein.

## Hauptexporte

| Export | Was es tut |
|---|---|
| `Einsatzzeichen({ drawing, size, theme, idPrefix, minStrokeWidthPx, className, style })` | die Komponente; gibt ein `<svg>`-Element zurück |
| `useEinsatzzeichenSvg(drawing, options)` | der Hook: liefert das SVG von `core` als String |
| `splitSvgMarkup(svg)` | zerlegt Markup in Wurzelattribute und Inhalt |
| `svgAttributeToReactProp(name)` | Attributnamen zu React-Props (`stroke-width` → `strokeWidth`) |

`idPrefix` ist nicht optional gedacht, wenn mehrere Zeichen im selben Dokument stehen: die
erzeugten Element-IDs müssen eindeutig bleiben.

`minStrokeWidthPx` macht die Striche kleiner Zeichen kräftiger: Bei 16 oder 24 Pixeln Breite sind
die feinen Striche der Vorlage schmaler als ein Bildpunkt und wirken blassgrau. Mit dem Wert werden
sie mindestens so breit gezeichnet; die Zeichendaten bleiben unverändert. Die Prop ist
standardmäßig aus, verlangt `size` (sonst `RangeError` aus `core`) und gilt ebenso für
`useEinsatzzeichenSvg`. Empfohlen ist `RASTER_MIN_STROKE_WIDTH_PX` (1 px) aus `core`; Hintergrund
auf der [Seite zu `core`](/docs/pakete/core/#kräftigere-striche-in-kleinen-bildern).

```tsx
import { RASTER_MIN_STROKE_WIDTH_PX } from '@einsatzzeichen/core';

<Einsatzzeichen drawing={drawing} size={24} minStrokeWidthPx={RASTER_MIN_STROKE_WIDTH_PX} />;
```

## Beispiel

```tsx
import { Einsatzzeichen } from '@einsatzzeichen/react';
import { RECIPES, composeFromCatalog } from '@einsatzzeichen/conformance';

const recipe = RECIPES['E.1.1'];
const drawing = composeFromCatalog(recipe.spec, recipe.title);

export function Bergungsgruppe() {
  return <Einsatzzeichen drawing={drawing} size={64} idPrefix="ez-e-1-1" />;
}
```
